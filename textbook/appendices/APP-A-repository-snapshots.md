# 附录 A　如何阅读仓库与固定版本

> 版本：v0.2
>
> 用途：为全书的真实项目案例提供共同访问指南，不要求读者预先掌握 Git。

## A.1 先把仓库看成一个带历史记录的项目空间

本书所说的**仓库（Repository）**，是保存项目文件及其变更历史的协作空间。它不只是若干文件的集合，还可能包含项目说明、许可、版本记录、问题讨论和变更评审。

初次阅读一个公开仓库，可以先识别以下几类材料：

| 材料 | 你可以先问的问题 |
|---|---|
| README | 这个项目做什么？主要入口和使用限制是什么？ |
| 文件目录 | 代码、文档、数据或其他材料分别放在哪里？ |
| LICENSE 或许可说明 | 哪些材料被授权？使用、修改和分享需要满足什么条件？ |
| 提交与发布记录 | 当前看到的是哪个状态？后来发生过什么变化？ |
| Issue 与 Pull Request | 项目正在讨论什么问题？一项变更怎样被提出和处理？ |

并不是每个仓库都包含全部材料，也不是存在同名文件就说明内容完整。第 2 章会进一步解释这些材料与协作记录。

## A.2 `0cf7856` 这样的字符串是什么

Git 用**提交（Commit）**记录项目在某个时点的一组变更，并为每次提交生成一个标识，通常称为**提交号**或 **Commit ID**。可以把它理解为项目历史中的一个“版本快照编号”：有了它，作者和读者就能尽量回到同一份材料，而不只是在不断变化的最新页面上各说各话。

提交号完整形式通常较长，平台常显示前几位作为缩写。例如：

- 本书 DeepSeek-R1 案例中的 `0cf7856`，是完整提交号 `0cf78561f1d51c84a21b2190626b21116d5c68bb` 的缩写；
- 本书 AIInfra 案例中的 `b97c038`，是完整提交号 `b97c0385ba07a62a717d82a0e7aed2927f12fc35` 的缩写。

这些编号不是模型版本号、软件发布版本号或许可证名称，也不代表项目质量。读者不需要记忆或手工输入完整编号，通过本书提供的固定链接即可访问相应页面。

## A.3 为什么案例要使用固定版本

在线仓库会持续变化。README 可能改写，文件可能移动，许可说明可能补充，今天看到的页面未必与教材写作时相同。固定版本主要帮助完成三件事：

1. **共同定位**：教师、学生和作者讨论的是同一份材料；
2. **核对证据**：读者可以检查教材的案例描述是否有原文依据；
3. **保留历史**：项目更新后，写作时使用的案例仍然可以回查。

固定版本也有边界。它固定的是 Git 仓库在该提交中的内容，不会同时冻结外部网站、在线服务、模型下载页面或 Issue 的最新状态。本书涉及动态社区记录时，还会另外给出记录编号和读取日期。

## A.4 怎样访问本书的案例

以 DeepSeek-R1 为例，可以采用两种入口：

- 想了解项目当前情况，可以访问 [DeepSeek-R1 官方仓库](https://github.com/deepseek-ai/DeepSeek-R1)；
- 想核对本书写作时使用的材料，可以访问[本书固定的 README 版本](https://github.com/deepseek-ai/DeepSeek-R1/blob/0cf78561f1d51c84a21b2190626b21116d5c68bb/README.md)。

打开固定页面后，不必通读整个仓库。可以先按正文提出的问题寻找对应部分，例如模型下载、本地运行、评测和许可。纸质版后续可为固定链接配置二维码；在尚未配置二维码时，读者也可以先通过项目名找到官方仓库，再根据提交号定位历史版本。**只阅读本书正文并不要求下载模型、安装 Git 或注册账号。**

本书前两章使用的入口如下：

| 案例 | 固定材料入口 | 阅读重点 |
|---|---|---|
| DeepSeek-R1 | [固定版本 README](https://github.com/deepseek-ai/DeepSeek-R1/blob/0cf78561f1d51c84a21b2190626b21116d5c68bb/README.md) | 产品入口、模型获取、运行说明、评测与许可 |

## A.5 阅读时保留三个边界

第一，**能打开页面不等于获得全部权利**。公开可见、开放许可和实际可复用是不同判断。

第二，**固定一个仓库不等于固定整个 AI 系统**。模型文件、数据、在线产品和外部文档可能位于其他平台，并有各自版本和条件。

第三，**看到协作记录不等于已经理解全部技术争议**。Issue 中的内容可能是报告者主张，PR 被合并也只说明项目接受了一项具体变更。必要时仍需核查原始证据和后续状态。

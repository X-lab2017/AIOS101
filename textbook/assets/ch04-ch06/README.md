1. **结构与文字以章节中的 Mermaid 源码及图题为正本。** 本清单用于汇总绘制要求，不另建一套可能失配的图内容；如确需调整节点或关系，应先修订正文并同步本清单。
2. 22 幅结构图需同时提供适合印刷的矢量版本和适合在线阅读的版本；文字横向排版优先，窄屏下可改为纵向，不依赖颜色才能读懂。
3. 每幅图提供图号、图题、替代文本和必要图注。教学示意、模拟轨迹、简化概率与二维嵌入必须在图内或紧邻图注中标明，不得只在正文中说明。

5. 真实材料截图须保留作者或项目、文档标题、固定版本、必要许可与署名。裁剪不能改变原意；需要多段拼接时标明“局部组合”，不以排版制造原文中不存在的邻接关系。
6. 正式出版前由维护者复核第三方素材的呈现和许可条件。本轮已按维护者授权制作并发布在线评审；不表示正式出版校样和课堂可读性已经实测。

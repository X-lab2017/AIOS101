# 在线版内容入口

本目录用于后续生成《AI 开源通识》在线阅读版本，不维护第二套教材正文。

## 内容来源

- 序言：`textbook/preface.md`
- 章节正文：`textbook/chapters/CHxx-*.md`
- 章节规格：`specs/chapters/CHxx-*-spec.md`
- 视觉资产：`textbook/assets/chxx/`
- 交互活动：`interactive/`

在线构建时应保留章号、标题层级、图号、活动 ID、来源和版本信息。当前正文中的“图片占位”和“交互占位”是后续集成锚点，不应被构建脚本静默删除。

## 集成原则

1. 教材 Markdown 是唯一内容正本，网页只保存配置、组件和派生结果；
2. 图片以稳定图号接入，替换占位时不得改变正文结论；
3. 交互组件以 `ACT-CHxx-nn` 接入，并保留无脚本、静态或离线替代；
4. 来源、许可、版本和结论边界必须随内容一起发布；
5. 每次正文更新后重新检查导航、锚点、移动端阅读和交互回退。

## 当前设计评审原型

本目录作为在线资源入口；本轮网站壳、品牌与通用评审活动源码位于 [site/](../site/README.md)，以 [网站规格](../specs/website-spec.md) 约定范围，运行 `python scripts/build_site.py` 生成静态 dist/。不在 online/ 或 site/ 复制教材正本。

序言已接入阅读；CH01 正文和两项正式活动已在仓库形成草稿，网站目前提供草稿入口，完整在线阅读及正式活动实现待接入。WEB-ACT-01／02 是序言导入与系统探索样例，不代表 ACT-CH01-01／02 已实现，也不替代学生任务单。

GitHub Pages 配置和私有评审托管说明见 [网站开发与发布说明](../site/README.md)。正式章节组件继续遵循本目录的内容来源与 interactive/ 的挂载约定。

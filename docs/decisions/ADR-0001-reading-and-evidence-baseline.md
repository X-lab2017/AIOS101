# ADR-0001：阅读优先、单一正本与证据保真

- 日期：2026-10-29；状态：已接受，整理维护者历次已明确的决定。
- 决策者：Will（王伟）；AI 协作者负责实现、检查和记录，不替代最终教学评审。
- 依据：课程宪法、当前网站与学习体验规格、维护者的图文阅读及材料整理指令。
- 替代：v0.4 交互体验基线的公开页面要求；品牌 v1.0.0 和课程学习成果保持有效。

## 背景与选择

早期原型同时提供手账、已读标记、活动表单与视觉展厅；教材与配图更新后，维护者要求先把图文阅读做好。随后又要求逐章按全体大学生能够完全自学的标准修改正文和插图。旧导出、早期规格和多处手写版本号继续混在当前入口，会使协作者恢复旧功能或覆盖新内容。

可以继续并排保留全部方案作为“当前基线”，也可以删除所有过程；前者制造冲突，后者失去决定与证据。采用当前入口集中、历史记录分开、被替代交付物从 Git 历史恢复的方式。

## 决定

1. **正文优先**：网站聚焦完整图文阅读。暂停已读标记、想法按钮、页边手账、工坊和活动表单；恢复须有明确学习需求。课程实践与静态任务单仍然保留，暂停网页交互不等于取消学习成果。
2. **每类材料一个正本**：教材在 `textbook/`，图版身份在 `manifest.json` 与规范正文图注，品牌在 `brand/`。网站、目录、状态表和图版索引从这些输入生成；PDF 与课件是有版本的派生稿。
3. **图像为理解服务**：保持现实材料、手绘科技出版感与清楚隐喻，允许人物、场景、实物、精确图解等不同构图。有效图不为统一风格而重绘，重复图可以退出正文。
4. **证据不生成式重绘**：真实界面的数字、文字、地图、节点、关系与状态保持原始证据。手绘用于装帧或概念表达；数值、结构和关系由可复算／可校验的原生排版生成。固定截图不是最新统计。
5. **图号稳定**：图 0-1、0-2、A-1 已撤销；4-8、5-4、6-9 退出正文。旧号不重新分配，不为填补空号而重新编号。正式交付使用自动图版索引。
6. **区分验收**：工程通过、已公开、维护者内容评审、真人试学、出版清权与印刷打样分别记录；不得将一次成功部署写成整门课程完成。
7. **过程可接手**：当前事实进入 `docs/STATUS.md`，重要决定进入 ADR，具体任务与未决项进入 Issue／工作记录。旧轮次保留原证据，不冒充当前状态。

## 实施与影响

当前 UI 不访问旧学习记录；历史数据逻辑与测试保留但不随 Pages 发布。来源与历史图件继续可在仓库查阅，部署只包含当前图版。根目录、规格入口与维护指南不再指向旧“待设计”清单或旧交互基线。

已替代的 Word/PDF、旧 Word 脚本、专用依赖和品牌提案包移出当前树，固定恢复清单保留；不改写历史。课件尚未逐页对齐，作为独立评审稿保留，不删除有教学价值的材料。

## 验证与复审

统一检查覆盖状态表、正文／图号／图题／来源、当前发布资产、旧路由和旧数据保护。视觉变更仍须实际看桌面、窄屏和放大页。出现新的教学需要、进入后六章或正式打印交付时复审相应范围；课程定位变化仍按宪法级流程处理。

未决事项以[当前状态](../STATUS.md)及维护 Issue 为准。本记录不新增统一许可、完成印刷验收或批准未审定封面。

## 2. 后续默认复用

| 对象 | 基线约定 |
|---|---|
| 品牌与视觉 | 开卷课程识别、纸白与靛蓝体系、X-lab 出品方署名、明暗主题 |
| 学习入口 | 学习首页、课程地图、探究工坊、个人手账 |
| 阅读 | 正本全文、分节目录、版本来源、字号、专注模式、书签和批注 |
| 探究 | 先观察材料，再表达判断与依据，再对照解释和修订 |
| 活动 | 分步任务、随时返回、草稿保存、反馈、修订历史与可带走的产物 |
| 数据与表达 | 本机保存、清楚标识模拟与真实材料、填写进度不冒充学习评价 |
| 可及性 | 无账号核心路径、小屏布局、键盘访问、可下载静态材料 |

普通内容更新直接复用上述形式。新章节可以选择已有适用组件，不要求每章都拥有相同数量的表单或同一种交互。新增交互应说明它帮助学习者完成哪项观察、比较、解释或创造，并尽量形成可复用组件。

## 3. 版本分开管理

- 视觉基线：v1.0.0，遵守现有品牌清单和资产校验。
- 体验基线：v0.4，基于上述实现提交；改变导航、学习流程或数据行为时记录体验变更。
- 教材版本：各章独立维护，按正文版本与 Git 提交追踪。
- 活动版本：对应 ACT/EVD ID 和教学规格；内容、字段或反馈实质变化须评审。
- 本机数据：当前 schema 2；字段删除、更名或语义变化须有兼容与迁移安排。

修正正文无需修改视觉版本。体验基线允许有依据的改善，保留旧记录和新版本关系；不得以基线冻结为理由保留已证实的可用性问题。

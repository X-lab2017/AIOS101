# 探究活动资源入口

本目录把同一项活动拆成面向不同使用者的材料，避免学生、教师和开发者从工程规格中猜测自己该做什么。活动目标、流程、产物与量规以根目录下的活动规格为共同依据，各类材料不得形成相互冲突的任务正本。

## 按角色使用

| 使用者 | 需要阅读 | 用来做什么 |
|---|---|---|
| 学生 | `student/` 中的任务单 | 了解目标、准备、步骤、提交内容、互评与自检要求，直接完成并导出或填写学习产物 |
| 教师 | `teacher/` 中的教学指南 | 备课、组织课堂、提问与反馈、处理常见误解、选择分层或替代路径 |
| 内容与课程评审者 | 根目录中的活动规格及对应章节规格 | 检查学习成果、活动内容、学习证据和评价量规是否对齐 |
| 在线与交互开发者 | `../interactive/` 中对应活动目录 | 实现用户流程、字段、保存与导出、反馈、隐私、可及性和离线回退 |

学生不需要理解工程编号才能开始学习。`ACT-CHxx-nn` 和 `EVD-CHxx-nn` 主要供规格追踪、交互挂载、导出和验收使用。

# AIOS101 · 开卷 / Open Folio

课程专属视觉识别 v1.0.0，已批准基线。X-lab 为课程出品方。

## 选择文件

- logo-light / logo-dark：浅底 / 深底的课程横版标志。
- logo-black / logo-white：单色标志。
- mark-*：独立图形标；favicon 为小尺寸专用版本。
- avatar、social-card：课程头像与社交预览。
- cover-part-1—4：四篇封面图形样板。
- tokens.json：数字设计参数；identity-board.svg 是 v0.1 历史评审板，不进入 v1.0.0 生产包。

SVG 为已转路径的矢量资产，不是位图描摹文件；使用时保持比例和净空。图形标建议 32 px 以上，横版字标常规建议 220 px 以上；紧凑手机导航最低 168 px，须核验辨识度。颜色为 sRGB，印刷须打样，不宣称已完成 CMYK 转换。

Space Grotesk 原始字体按 SIL OFL 1.1 随包提供。Phosphor 辅助图标按 MIT 分别保留许可。中文固定字形使用 Noto Sans CJK SC 转路径，完整中文字体未打包。Radix Colors 和 p5.js 仅为调研参考，未打包其代码。第三方许可不自动适用于新课程标志或整仓库。

维护者已授权本基线用于 AIOS101 课程及配套资源复用；其他用途的对外复用条款由维护者决定。X-lab 标志应从其官方品牌库获取，保留原样作为出品方署名，不与课程图形合并。

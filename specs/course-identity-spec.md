# AIOS101 课程视觉识别规格

> ID：VIS-AIOS101 · v0.1 · 2026-10-28 · 状态：设计评审中
> 上游：[课程宪法](../CONSTITUTION.md)、[课程总规格](course-spec.md)、[展现规范](presentation-spec.md)、[网站规格](website-spec.md)

## 1. 定位与本轮授权

维护者要求为 AIOS101 搜索匹配的 GitHub 视觉与设计资源，并建立课程专属 Logo 和视觉方案。本轮形成可审阅的识别系统、生产资产及网站应用，保持评审状态。

课程名称仍为“AI 开源通识”，短名称 AIOS101；英文描述为 AI & Open Source Literacy。面向所有专业，表达好奇、证据意识、开放协作与创造。X-lab AI 保留为出品方，课程拥有独立的主标志、色彩和图形语言。

## 2. 标志概念：开卷 / Open Folio

两片向外展开的折叠书页构成开放的知识空间；内折边隐含括号，呼应可阅读、可修改的开放材料；中间留白保持开放；上方的珊瑚橙方块代表学习者提出的问题。Logo 以几何路径重新制作，图像生成概念板仅用于创意预览，不充当生产母版。

标志不作机器人、脑回路或自动生成星芒的字面表达。101 代表入门课程的亲近感，不能把 AIOS101 解释为 AI 操作系统产品。

## 3. 品牌层级与组合

- 一级：课程图形标 + AIOS101 字标；中文课程名作为必要识别说明。
- 二级：课程信息与学习入口。
- 署名：X-lab 出品 / A course by X-lab。官方网站页脚保留正式 X-lab AI 横版 SVG。
- 不重绘、改色、拉伸 X-lab 标志，不把两个标志合成新商标；沿用其留白和深浅版本规范。

图形标四周至少保留标志宽度 1/8 的净空。常规图形标建议不小于 32 px；24 px 及以下使用简化 favicon。横版字标建议宽度不小于 220 px。黑白版保留页面折线的负形。深色承载面使用专门反白字标，不直接把浅色字标反相。

## 4. 色彩与排版

| 角色 | sRGB | 用法 |
|---|---|---|
| 暖纸白 | #F6F3EB | 大面积阅读底色 |
| 深墨蓝 | #1D2433 | 正文、单色标志与深色背景 |
| 开卷靛蓝 | #5146D9 | 课程主色、主要按钮、链接 |
| 问题珊瑚橙 | #F27A59 | 问题方块、少量强调与插图 |
| 纸页浅紫 | #E7E3FC | 辅助面板、折页层次 |
| 协作青绿 | #3F958D | 共同创造篇的辅助图形 |

珊瑚橙与青绿不直接用于浅底小号正文。浅底链接使用深靛蓝；深色主题切换为浅紫强调和较亮正文。颜色与章节名、编号、图标配合，不作为唯一状态信息。实际主要文字组合计算 WCAG 相对亮度对比值；不把单项颜色检查称为完整无障碍验收。

英文字母、数字和课程字标采用 Space Grotesk；网页本地托管原始 WOFF2。中文网页采用系统无衬线字体回退；固定字标和封面使用 Noto Sans CJK SC 字形转路径。交付 SVG 不要求查看者安装字体。标题、正文和辅助信息保留清楚层级，正文不因视觉效果缩小。

## 5. 四篇视觉与图形语法

| 篇章 | 图形动作 | 辅助色 | 辅助图标 |
|---|---|---|---|
| 认识开源 | 两页向外打开 | 靛蓝 | 打开的书 |
| 理解 AI | 折页逐层拆开 | 浅紫 / 深靛蓝 | 关系图 |
| 探究证据 | 方块与路径逐步对齐 | 珊瑚橙 | 放大镜 |
| 共同创造 | 多条路径汇合 | 青绿 | 分支协作 |

辅助图形使用固定网格、折面、开口、方块和连接路径。它们表达课程结构，不伪装为神经网络实测图或生态数据。封面、活动卡、网站和社交预览共用这套规则。动画仅用于操作反馈，支持减少动态偏好，不自动播放持续背景动画。

## 7. 交付与目录

- `site/assets/course/`：浅底、深底、黑白标志，简化 favicon、头像、四篇封面、社交预览和设计 tokens。
- `site/assets/fonts/`：本地 WOFF2 与 OFL。
- `site/assets/icons/`：四枚 Phosphor 原始 SVG 与 MIT 许可。
- `site/brand.js`、`site/brand.css`：品牌展示页及课程界面应用。
- `scripts/generate_course_brand.py`：生产资产的生成源码；日常网站构建使用已提交的 SVG，无需安装字体处理依赖。
- `#/identity`：双语在线视觉评审页，包括标志、深浅应用、配色、封面、资源来源与下载。

压缩包包含可直接使用的 SVG、色彩 tokens、来源及使用说明，不将生成式概念图当成可编辑矢量文件。

## 8. 验收与后续

本轮核对 SVG 结构、外部引用、资产完整性、主要颜色对比、网站构建、页面深浅色与移动布局，并检查既有活动入口与记录功能未被品牌更新破坏。资产仍为设计提案；印刷 CMYK、实际材料打样、完整无障碍审计及商标可注册性未验证。

设计确认后，将同一套标志和四篇图形延伸至教材封面、课件、视频片头和活动任务单；每次新增用途记录版本与调整理由。

本轮执行记录见[课程视觉核验记录](course-identity-review-record.md)。维护者已认可“开卷”方向，并要求结合 X-lab 出品方标志上线本版评审。

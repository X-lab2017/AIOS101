## 1. 范围与学习者

以教材为正本，为全专业本科生及公众建立“阅读—观察—解释—修订—留下产物”的数字配套。核心路径不要求编程、GPU、外部账号或付费 API。课程结构、学时、学习成果与评价权重保持课程总规格；网站填写进度不作为学习成绩。

维护者在绪论与前两章更新后要求系统性重构体验，本版本取代 v0.3“前两章全文和正式活动待接入”的旧范围。v0.3 设计与原评审记录留在版本历史、[早期核验记录](website-review-record.md)与[原型活动规格](website-activities.md)，不再作为当前实现状态。

## 2. 课程与页面

完整接入序言 v0.3（界面称“绪论”）、CH01/CH02 v0.4 和附录 A；第三章 v0.1 新草稿自动接入阅读，定制活动待制作；CH04—CH12 保留计划，不补造正文。三个观察窗与四项 ACT 活动对应教材和学生任务单。具体页面、字段、数据和核验契约见[WEB-LEARN-AIOS101 学习体验规格](learning-experience-spec.md)。

| 页面 | 学习者任务 |
|---|---|
| 学习首页 | 选择起点，继续上次章节或活动 |
| 课程地图 | 查看十二章、搜索正文、了解上线状态 |
| 完整阅读器 | 分节阅读、书签、批注、调整字号与专注模式 |
| 案例观察窗 | 观察材料，提出有依据且有边界的判断 |
| 探究工坊与活动 | 分步形成产物，保留反馈、初稿和修订 |
| 个人手账 | 回顾变化，备份、恢复、导出或打印 |
| 资源与视觉页 | 回查术语、固定来源、版本和视觉资产 |

## 3. 视觉与可及性

沿用“开卷”课程识别、纸白与靛蓝主色、X-lab 出品方署名、已冻结图形和字体；不建立新的视觉正本。阅读优先于装饰。桌面提供目录与页边手账，小屏采用可展开目录与批注编辑窗。表格允许局部横向滚动，正文和表单不得撑破视口。

支持键盘访问、可见焦点、跳过导航、语义按钮、对比清晰的主题与减少动态效果。核心界面双语，中文教材、任务单及案例解释明确译本未审定。兼容性检查不替代完整无障碍审计。

## 4. 来源与个人记录

教材 Markdown 是唯一正文正本，构建生成完整内容、分节 ID、版本、摘要校验和提交链接。已有插图占位不静默删除。新交互是数字学习支架，不冒充实测架构、正式插图或真实社区提交。

个人记录存于当前浏览器，保留原始解释、反馈来源和修订。导出与恢复须验证输入、明确合并影响、保留恢复前备份。真实案例与模拟活动分开标识，不自动生成成绩、同伴意见或外部贡献记录。

## 5. 发布与评审

site/ 为源码，scripts/build_site.py 生成 dist/；GitHub Actions 检查后发布 GitHub Pages。所有站内资产使用相对路径，兼容 /AIOS101/ 子路径。个人数据不进入仓库；不向访问者要求 GitHub 登录。维护者私有 Sites 预览受众保持不变。

正文存在只表示可以阅读，工程检查通过只表示所列技术核验通过。本次为学习打样，正式教学认可由维护者和真实学习者评审。[核验记录](learning-review-record.md)须列明已执行及未执行项，重点收集阅读连贯性、证据理解、任务负担和修订产物的反馈。

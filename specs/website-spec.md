## 1. 本轮授权与边界

维护者在本轮对话中授权设计网站规格、页面及活动，并上线供本人评审。本轮同步制作有限范围的交互原型；规格状态保持评审中，不代表课程、序言或章节通过教学验收。所有页面显示设计评审状态，未上线章节保留计划说明。课程结构、学时和考核权重不作变更。

## 2. 定位与学习者

以教材正本为基础，把阅读、观察、证据表达和修订连成可保存的学习过程。面向全专业本科生及公众，不以编程、GPU、付费模型或第三方账号作为核心路径门槛。X-lab AI 为课程出品方。

## 4. 学习结构与评价

所有正式章节沿用“问题导入—概念建构—开源解剖—探究实践—证据表达—贡献与反思”。本轮活动支持 LO1 的导入，不宣称独立完成 LO1—LO6。阅读完成、活动记录、成果达成分别表示；原型不颁发证书、不自动判定课程成果。

活动规格见 [WEB-ACT-01](website-activities.md)。WEB-ACT 与 WEB-EVD 为评审原型暂用命名空间，正式章节活动经批准后映射至现有 ACT-CHxx-nn 与 EVD-CHxx-nn；保留迁移对应表，不复用旧 ID。

## 5. 内容接入契约

教材唯一正本保留在 textbook/。构建时从课程总规格和宪法提取章节 ID、篇章、章名、核心问题与成果，形成网站数据；原型将尚未上线阅读的章节标为待接入，不另写章节正文。site/assets/ 保存必要品牌资源及来源说明。scripts/build_site.py 从 Markdown 正本提取完整序言并生成 dist/content.json，复制网站源文件至 dist/。

本轮制作期间，主分支新增 CH01 正文草稿、学生任务单、教师指南及交互开发需求，已同步保留。课程地图为 CH01 提供固定版本草稿与任务单入口；完整在线阅读及 ACT-CH01-01／02 尚待接入。WEB-ACT-01／02 是独立导入样例，不视为正式章节活动的实现。online/ 保持在线资源入口，site/ 保存本轮网站壳与通用原型；正式章活动继续按 interactive/ 的稳定 ID 挂载。

后续章节最低接入字段：章节 ID、上游规格、正文路径、固定版本、审定状态、来源、活动及学习证据 ID。缺失字段显示待接入；不得生成虚构教材填满目录。正文变化后重新构建，并核对活动、翻译、打印与来源同步状态。

## 6. 品牌与可及性

课程采用 [Open Folio / 开卷专属视觉](course-identity-spec.md)：课程标志位于导航与首页，X-lab AI 官方标志用于出品方署名、页脚与联合展示。X-lab 原 SVG 保持比例、原色、AI 上标与留白；课程标志拥有独立的靛蓝、珊瑚橙和暖纸白体系。

视觉评审页展示四种 Logo 版本、联合署名、色卡、四篇封面、字体、来源和下载。主要文字对比、窄屏与主题切换分别核验；支持键盘焦点、减少动态偏好与打印样式，颜色不作唯一状态提示。

界面提供中英切换。正式教材当前仅有中文；英文界面进入阅读时明确提示中文原文与英文翻译待审，避免把界面翻译称为全课英文版。

## 7. 数据与个人记录

学习记录保存在当前浏览器 localStorage，不上传到课程仓库或服务器，不要求填写姓名。首次使用说明保存范围；提供版本化 JSON 导出/导入和打印，同时提供可手动复制的备份文本及文本恢复入口。导入进行类型、字段、长度与格式校验，保留其他记录并按内容项合并；外部文本只以文本呈现，不能执行 HTML。清除记录须用户二次确认。

本地记录不能自动跨设备同步，清除浏览器数据可能丢失。存储被禁用或容量不足时显示明确提示，当前会话仍可导出。评审反馈同样仅本地保存，由维护者主动导出或复制分享。

## 8. 来源与素材

序言采用仓库正文，恢复独立的来源入口和证据边界说明。OpenDipper 截图因来源登记仍有限定用途，本轮不复制展示，保留图题与项目链接。系统交互图为课程概念示意，不代表某款产品的实测架构或依赖图。

品牌资源由维护者在本轮明确提供用于 X-lab 出品课程；保留原品牌 NOTICE，不增设通用授权。教材和网站代码统一许可仍由维护者决定，不擅自套用 MIT 或 CC。

## 9. 技术与发布决策

本轮采用原生 HTML/CSS/JavaScript、Python 标准库构建，形成可托管于 GitHub Pages 的静态 dist/。这是有限范围评审原型的实施选择；后续正式内容规模扩大时，再评估 Docusaurus 的迁移价值，教材正本与活动数据保持独立。

源码与规格以 AIOS101 评审分支及 PR 为协作入口。Sites 托管精确源码快照，提供维护者私有评审地址。当前 GitHub 插件无 Pages 开通接口；GitHub Pages 部署配置随 PR 提供，首次在仓库 Settings → Pages 选择 GitHub Actions 后，可由维护者选择合并并发布。私有 Sites 访问控制不代表正式课程需要登录；正式核心教材按上游规范公开免登录。

正式发布与设计预览使用独立状态。序言与章节仍在评审时，不把部署成功表述为教学验收成功。发布包记录网站版本、教材版本、品牌版本及提交号；后续依据已验收内容发布。

## 10. 验收条件

以下是正式验收目标；本轮已执行项目及剩余限制逐项记录于[技术核验记录](website-review-record.md)，不将原型核验直接等同于教学验收。

- [ ] 首页品牌与深浅主题正确，移动端无横向溢出。
- [ ] 四篇十二章编号、章名及核心问题与课程总规格一致。
- [ ] 序言全文由正本生成，无隐藏删节；评审状态与来源入口可见。
- [ ] 核心活动无需外部模型、GPU 或 API 密钥即可完成。
- [ ] 问题卡和实验记录可保存、刷新恢复、导出、校验后导入。
- [ ] 导入内容不能注入 HTML，错误文件有可理解提示。
- [ ] 所有导航、筛选、主题、语言及主要活动可操作。
- [ ] 已读状态不被用于宣称学习成果达成。
- [ ] GitHub 基础检查、构建及浏览器核验有真实记录。
- [ ] 正式教学批准与技术部署状态分别记录。

## 11. 迭代顺序与评审关注点

第一步：本轮框架、序言、系统探究与学习档案。第二步：接入首个已批准章节，验证活动与评价闭环。第三步：开放度核查、生态数据探究与贡献档案。第四步：按实际教学需要加入班级协作和有引用的 AI 提示功能。

本轮请重点评审：X-lab 品牌辨识、页面阅读节奏、十二章导航、无代码活动是否促成解释、个人学习记录是否有价值。学时、评分权重、正式统一许可和英文正文批准保留为后续决策。

## 1. 章节定位

### 1.1 核心问题

为什么“会使用 AI”还不等于“理解 AI”？从软件开源的历史出发，开源为 AI 通识教育增加了哪些理解、验证、协作与创造的可能？

### 1.2 本章价值

本章是全书的认知起点。序言提出课程问题，本章进一步建立三组基本判断：使用不等于理解；开源不等于免费或源码可见；AI 开放不能只检查代码或模型权重。软件开源史用于解释这些判断从何而来，并服务后续第二章的开源机制与第三章的 AI 开源生态全景。

### 1.3 目标学习者

面向所有学科背景的大学生。不要求编程、机器学习或开源社区经验。针对“开源属于程序员”“免费就是开源”“会写提示词就是 AI 素养”等先入认识提供概念支架。

### 1.4 建议学习时间

| 部分 | 建议时间 | 说明 |
|---|---|---|
| 教材学习 | 60—90 分钟 | 含概念辨析、真实仓库案例与思考问题 |
| 课堂活动 | 45—60 分钟 | 对照分析、讨论与互评 |
| 探究实践 | 55—75 分钟 | 独立完成两项无代码活动 |
| 反思与修订 | 15—20 分钟 | 根据反馈修订学习问题地图 |

## 4. 内容范围与边界

### 4.1 必须覆盖

- 使用 AI 与理解 AI 的差异；
- GNU 与 Richard Stallman、自由软件四项自由；
- Linux 与 Linus Torvalds 所代表的公开源码、反馈与协作开发；
- “open source”术语、OSI、Eric Raymond、Bruce Perens、Christine Peterson 及开放定义；
- 自由软件与开源在价值表述上的差异及实践重叠；
- 从软件到 AI 后，代码、数据信息、参数、文档、评测与许可问题；
- 开源服务理解、验证、协作和创造的教育价值及其边界。

### 4.2 可选拓展

- 阅读 GNU 初始声明、OSD 与 OSAID 1.0 的原文片段；
- 比较早期共享文化、自由软件运动与开源运动的不同叙述；
- 探讨开放知识与开放教育资源和软件开源的关系。

### 4.3 明确不覆盖

- 完整的软件开源编年史与人物谱系；
- 许可证条款比较与合规操作，留待后续章节；
- 模型开放度分级判定，留待 CH07；
- 模型训练、部署或代码实现；
- 对任何现实 AI 产品作未经核查的开源认定。

### 4.4 稳定内核与时效内容

| 类型 | 内容 | 更新策略 |
|---|---|---|
| 稳定原理 | 使用—理解—创造、四项自由、协作与复用 | 随认知框架修订 |
| 历史事实 | GNU、Linux、OSI 的时间、人物与文献 | 以原始来源复核，不随热点变化 |
| AI 开放定义 | OSAID 1.0 的四项自由与修改所需材料 | 固定版本，后续版本另增来源记录 |
| 真实案例 | DeepSeek-R1 官方仓库中的产品入口、模型下载、运行说明与许可 | 固定提交，案例变化时新增来源而非覆盖历史 |
| 工具操作 | 本章不设置 | 后续在线交互不得引入全员门槛 |

## 5. 建议内容结构

1. **问题导入**：从使用 DeepSeek 等 AI 工具的日常场景，区分产品、模型与开放材料；
2. **历史建构**：GNU、Linux、OSI 三个历史坐标，解释自由、协作和开放定义；
3. **概念迁移**：将使用、研究、修改、分享的问题带入 AI，指出软件类比的边界；
4. **真实解剖**：阅读 DeepSeek-R1 官方仓库，分析模型下载、代码、文档和许可分别支持什么判断；
5. **教育命题**：开源如何支持理解、验证、协作与创造，同时保留质量和责任边界；
6. **思考与延伸**：保留少量开放问题，完整活动放入独立任务单和在线资源。

## 7. 教材与讲义规格

### 7.1 教材正文

- 预期篇幅：约 5000—8000 中文字，以适合打印阅读的完整叙述为目标；
- 必须解释：自由软件、开源、四项自由、源代码、许可、复用、开放材料、AI 系统、模型参数、开放权重、使用—理解—创造；
- 必须区分：官方定义、本书工作定义、真实案例事实与尚待后续章节验证的判断；
- 必须使用真实材料：DeepSeek 日常工具场景与 DeepSeek-R1 官方仓库，提供固定版本链接和结论边界，并在首次出现提交号时说明其含义与附录入口；
- 必须提供：必要概念卡、真实案例解读、少量思考问题和有明确阅读目的的延伸学习；不在正文展开活动步骤、练习答案、角色评审或交互说明；
- 图 1-1 至图 1-3 使用可维护的 Mermaid 结构图；图 1-4 为 DeepSeek-R1 固定 README 的真实截图占位，须注明所需画面与教学用途；首次出现 API 时解释其基本作用；
- 正文无需访问外部链接即可完成核心学习，外部材料只用于自主核查与延伸阅读；
- 章末不设置资料来源汇编或任务单链接；完整证据链集中保留在来源登记，跨章仓库访问知识由附录 A 统一承担；
- 必须使用来源：`SRC-2026-005`—`SRC-2026-010`、`SRC-2026-016`；
- 必须保留：自由软件与开源的差异、Linux 早期发布与后来开源定义的区分、公开不自动产生公共价值；
- 章末小结必须回答：为什么 AI 通识教育需要开源，以及学习者能从此开始做什么。

## 1. 章节定位

### 1.1 核心问题

数据、算法、算力与训练过程如何共同塑造模型能力？模型参数究竟怎样从学习过程中形成，开放材料又能把这一形成过程解释到哪一步？

### 1.2 本章价值

第三章建立了 AI 开源生态的资产与关系全景。本章沿“数据—训练—参数”深入模型形成过程，使学习者不再把模型理解为资料数据库、规则清单或神秘黑盒，也不把能力归因于某一个要素。通过 FineWeb 的真实数据处理与对照实验，学习者看到数据配方可以被观察、比较和改进；通过 DeepSeek-R1 的固定训练说明，学习者区分预训练、后训练、监督微调、强化学习与蒸馏。本章为第五章“已经形成的模型怎样运行与评价”和第六章“模型怎样进入任务”提供必要而不过量的基础。

### 1.3 目标学习者

面向所有学科背景的大学生，不要求编程、微积分、线性代数或模型训练经验。针对“训练就是把资料原样存进模型”“参数就是知识条目”“数据越多必然越好”“强化学习等于有人逐条批改”“蒸馏就是压缩或复制权重”“公开权重就能复现训练”等常见误解提供图示、类比边界和真实材料支架。

| 部分 | 建议时间 | 说明 |

### 2.3 常见误解与诊断

| 常见误解 | 形成原因 | 诊断问题／任务 | 纠正方式 |
|---|---|---|---|
| 训练就是把所有资料原样存入模型 | 把生成模型当成检索数据库 | 没有原文检索时，参数怎样影响新输入的输出？ | 区分数据统计规律、参数状态与原文存储；检索留待第六章 |
| 参数就是逐条知识和人工规则 | 忽略数值表示和分布式统计模式 | 参数由人工逐条写入，还是训练迭代形成？ | 用预测误差和更新循环解释，不把参数拟人化为信念 |
| 数据越多，模型必然越好 | 忽略质量、覆盖、配比和任务 | 重复、错误或无关内容增加会带来什么？ | 结合 FineWeb 的过滤、去重与对照实验分析 |
| 算法、模型结构和模型是同一个概念 | 日常术语混用 | 谁规定计算形式，谁规定更新方法，谁是学习后的对象？ | 分别定义结构、学习算法、参数与模型 |
| 后训练就是继续进行同一种预训练 | 忽略数据和反馈目标变化 | 示范回答、奖励信号和下一词预测有何不同？ | 对比 SFT、RL 与预训练的目标和材料 |
| 强化学习一定由人逐条评分 | 把一种反馈来源当成全部机制 | 奖励是否一定直接来自人？ | 说明奖励可来自规则、程序、偏好模型或人工反馈，具体项目须核查 |
| 蒸馏等于复制或无损压缩大模型 | 忽略新样本和另一个基础模型 | 蒸馏训练的数据从哪里来，参数在哪个模型上更新？ | 用 DeepSeek-R1 蒸馏说明教师样本与学生基础模型 |
| 测试集表现好就证明真实能力全面 | 忽略泄漏、任务覆盖与评价条件 | 测试题是否进入过训练或调参，测试覆盖哪些情境？ | 本章解释数据证据，完整评估留待第五章 |
| 公开权重等于可以复现训练 | 混淆形成结果和形成过程 | 是否公开了数据信息、处理代码、配置、资源和实验记录？ | 按具体行动核查材料，不预设全部原始数据必须无条件公开 |

## 5. 建议内容结构

1. **问题导入**：从 AI 回答退回模型形成之前，提出“资料怎样变成能力”；
2. **形成要素**：解释数据、结构、算法、参数和算力，建立整体图；
3. **数据配方**：以 FineWeb 处理链和消融实验解释数据决策及对照证据；
4. **参数形成**：用下一 token 预测和训练循环解释损失、更新与迭代；
5. **能力塑造**：区分预训练、后训练、SFT、RL 与蒸馏，解剖 DeepSeek-R1；
6. **数据证据**：解释训练／验证／测试划分、过拟合与泄漏；
7. **开放解剖**：比较 FineWeb 与 DeepSeek-R1 公开材料可以支持的理解、比较、适配与复现边界；
8. **承接下文**：模型形成之后，如何运行、产生不同输出并被评价，留待第五章。

本轮只确定课程级最低证据与章节对齐，不虚构任务步骤、实验结果或学习者反馈。AI 可协助整理材料，但变量判断、结论边界和最终产物需由学习者核查；具体要求由后续活动规格规定。

## 9. 来源、数据与许可

FineWeb 使用 arXiv:2406.17557v2，论文页面标注 CC BY 4.0；数据集许可为 ODC-By 1.0，并受 Common Crawl 使用条件约束。本章只重述已阅读的来源规模、处理流程和实验设计，不复制数据集，不将论文报告的结果写成课程独立复算。现有图版的来源与转换见图源登记，正式复用需保留作者、标题、版本、许可和修改说明。

DeepSeek-R1 使用固定 README 的 Model Summary、Model Downloads 与 License 部分，仅作事实重述与链接。README 的概述不足以证明完整训练数据、全部配置或训练可复现；六个蒸馏模型的上游基础与生成样本分别呈现，不扩写未公开训练细节。

## 10. 风险与替代方案

| 风险 | 影响 | 预防 | 替代方案 |
|---|---|---|---|
| 数学和工程细节过多 | 非专业读者退出 | 以机制图和文字解释为主，不设数学先修 | 进阶公式进入后续独立资源 |
| 把训练类比成学生读书后停在类比 | 形成拟人化和数据库误解 | 类比后必须回到预测、误差和参数更新 | 用训练循环和反例纠正 |
| 案例结果被误写为课程复现 | 证据等级失真 | 明示论文报告、固定材料和本书解释 | 只比较公开设计与结果，不声称重训 |
| FineWeb 与 DeepSeek 案例被混用 | 错误构造模型供应链 | 两个案例分节并明确无此来源声明 | 分别绘制数据处理链和模型形成链 |
| 数据划分提前扩张成评价课 | 与第五章重复 | 只讨论训练证据有效性 | 将生成配置和综合评价留待第五章 |
| 外部素材许可不清 | 阻碍出版 | 保留来源、版本和授权条件 | 先使用文字重述和 Mermaid 自绘图 |
| 设备或算力不足 | 实践不公平 | 核心活动采用公开实验阅读 | 进阶只复现小样本处理，不训练大模型 |

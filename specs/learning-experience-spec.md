## 1. 当前目标与范围

先做好教材正文的图文阅读，减少一切与阅读无关的干扰。首页以 CH01—CH03 和 16 幅教材图为主线，保留绪论入口。已存在的其他章节与附录仍可从目录访问，不删除正文、不改变课程教学目标和活动规格。

本版替代 v0.9 的公开交互体验要求。原活动、笔记和进度功能暂不上线，恢复须另行确认具体学习需要。原实现可从 git 历史回溯（00d7f42 及以前），核心数据逻辑和任务单文件保留。

## 2. 页面契约

- 顶部只保留首页、教材目录、语言和明暗主题。
- 首页以课程定位、前三章的内容与插图、开始阅读为主；去掉手账、学习进度、工坊、活动和视觉资源推广。
- 阅读页采用左侧目录＋正文的双栏布局，正文约 780px；窄屏为单栏和可展开目录。
- 去掉逐节已读标记、想法按钮、页边手账、笔记提示、章末“带着问题动手”、配套活动、学习产物填写和进度。
- 只保留阅读相关控制：章节切换、目录锚点、字号、上一章／下一章、查看大图。来源与版本置于章末低干扰折叠区。
- 图片保持原比例和清晰度，不改变正文结论、图号、图注及证据边界。源码与关系文字以默认折叠形式保留。
- 教材目录提供正文搜索；先显示前三章，其他已有正文与课程后续目录保持可访问。
- 旧工坊、活动、手账、视觉页等路由回到目录或相应正文，不再展示交互表单。

## 3. 数据与可维护性

教材 Markdown 是唯一正文正本；本轮不编辑章节内容。前台不读取、不写入、不删除旧 learning.v1/v2 学习记录；仅保存语言、主题和字号偏好。停止加载活动数据、活动核心和品牌展厅脚本，保留其仓库文件及既有测试，便于后续恢复。

首页章节标题、估读时间与图版来自构建数据及固定图号映射；不再使用过期“前两章已开放”与旧版本文案。发布绑定 JS、CSS 与内容版本，避免缓存混用。

## 4. 验证与边界

必须验证：全文摘要未变化、16 图齐全、无活动／笔记控件、旧路由有回退、章节和目录跳转、字号调整保持阅读位置、主题和键盘访问、构建与 Pages。不得将静态检查写成真实设备或课堂测试。正文英语翻译尚未提供，英文界面明确说明。

正式出版的第三方素材条件仍见 textbook/assets/figures/README.md；本轮只调整在线体验。

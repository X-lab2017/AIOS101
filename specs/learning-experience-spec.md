## 1. 学习者需要完成的事

从正在使用的 AI 提出一个问题，阅读对应概念，核对具体材料，形成有边界的解释，回看并修订自己的学习产物。无需编程、账号、GPU 或付费 API。阅读、填写、评审和能力达成分开表示。

| 单元 | 原文 | 数字支架 | 学习产物 |
|---|---|---|---|
| 绪论 | 序言 v0.3 全文 | 五层系统展开、起点问题 | WEB-EVD-01／02 |
| 第一章 | CH01 v0.5 全文 | DeepSeek-R1 材料观察、支持与过度推断辨析 | EVD-CH01-01 对照分析、EVD-CH01-02 问题地图 |
| 第二章 | CH02 v0.5 全文 | AIInfra Issue／PR 两条独立记录对读、四次虚构发布比较 | EVD-CH02-01 机制分析、EVD-CH02-02 模拟贡献方案 |
| 第三至六章 | CH03 v0.2、CH04 v0.1、CH05 v0.2、CH06 v0.1 全文 | 自动全文阅读与 Mermaid 文字回退，定制支架待制作 | 对应任务单待制作 |

## 2. 页面与连续体验

- 学习首页：继续上次阅读、三个可用单元、下一步活动与个人手账入口；首次访问从绪论进入。
- 阅读器：完整教材分节导航，章节切换、字号与专注模式、逐节自主已读、书签、边读笔记；正文与来源可回查。
- 章节探究：概念示意与基于教材固定材料的观察窗。先判断再看解释，提示不替学生作开源认定或生成分数。
- 探究工坊：按章选择四项正式任务单；分步输入、前后跳转、草稿自动保存、缺项提示、人工反馈、修订记录和导出。
- 学习手账：分开呈现阅读记录、笔记、起点问题与活动产物；支持 JSON 备份恢复、Markdown 导出与打印。
- 课程地图：十二章、四篇、搜索、上线状态；附录与术语资源可独立访问。
- 保留课程视觉页与中英文界面、亮暗主题。教材与活动正本暂为中文，英文界面明确翻译状态。

旧链接 #/preface、#/lab、#/notebook、#/map、#/identity 保持有效。

## 3. 活动契约

四项活动沿用现有 ACT 与 EVD ID，以 activities/student/ 下的任务单为教学正本。在线表单采用等效字段分组，不省略案例、初判、证据、结论边界、反馈来源、修订及 AI 披露。分步界面始终可回退，保存草稿不要求填满。

ACT-CH01-01 保留三个理解问题、四种行动、三种学习位置、历史连接与边界。ACT-CH01-02 保留原始与改写问题、七类证据的理由和状态、优先级、低门槛行动、贡献设想及后续章节。ACT-CH02-01 保留四次虚构发布、八项复用条件、七个协作环节、三个断点与三个公共价值未知。ACT-CH02-02 保留情境、需要、范围、贡献初稿、维护成本、模拟评审、回应、修订稿与公共价值说明。

真实材料观察是阅读辅助；不以实际 AIInfra Issue 与 PR 替换任务单的虚构项目，不把两条记录串成同一个修复过程。它们的状态按教材读取日标注。模拟贡献不提供真实提交按钮。自动提示只检查缺项或讲解教材中的证据边界，不生成同伴意见、成绩或真实社区状态。

## 4. 内容与构建

构建从 Markdown 正本生成全文与分节数据，保留原始 Markdown、版本、状态、文件路径和提交号。相对教材链接优先落到站内阅读，其余链接解析到同一固定提交。源码中的图片占位保留为待配图文字；新的交互概念图单列为数字学习支架，不冒充教材正式插图或实测架构。

教材 Mermaid 结构图在 GitHub 保留可维护源码和原生渲染；学习网站不引入外部图形运行依赖，构建时将简单节点与连线转为可读的关系列表，并保留 Mermaid 源码展开入口。无法解析的语法须以转义源码回退，不得丢字或显示未转义 HTML。

正文无需另行复制到 site/。活动界面定义放在 site/learning-data.js，与教学任务单对应；构建同时提供任务单全文与可下载 Markdown 回退。素材不引入新的外部运行依赖，已批准品牌包不改动。教材更新触发 Actions 重建全部阅读数据；新章节自动进入阅读目录，定制活动按 ID 另行挂接。

## 5. 个人数据与迁移

采用浏览器本地 schema 2：reading、notes、activities、explorations、start、legacy、lastRoute。旧 schema 1 保留原记录并迁移起点卡和序言已读状态；旧系统探究与评审原文保留在历史记录中。原存储键不删除。

输入按事件保存，阅读位置和活动步骤可恢复。活动显式保存修订快照，导出包含初稿、反馈、修订、缺项与来源；完成仅为个人填写确认。修改后回到草稿状态。JSON 导入限制大小、字段、类型与长度，验证后展示恢复影响并确认；保留导入前自动备份，不执行输入 HTML。个人文字按文本转义显示。

不提供云同步或收集真实姓名；说明当前浏览器保存范围。存储失败时保留当前会话和导出路径。清除需要二次确认。导入失败不改变现有数据。纯静态站首次加载仍需网络；任务单下载后可离线使用，不声称完整网站离线缓存已实现。

## 6. 核验条件

- 全文与正本逐字一致，十二章编号及状态正确，内部教材链接可用。
- 四项任务单的必需字段、前后步骤、修订前后内容与导出对应。
- 数据迁移、刷新恢复、严格导入、错误输入、冲突恢复与模拟标识有验证。
- 桌面、320／390／768 px、明暗主题、中英界面、主要键盘路径经过浏览器检查。
- 观察窗选择能更新内容，结论反馈保留依据与边界，不以点击数判定学习成果。
- 构建、来源与资产检查、核心数据逻辑测试和 Pages 部署状态有实际记录。

完整屏幕阅读器审计、真实设备测试、课堂学习效果与正式教学批准另行开展。打样评审重点：阅读是否连贯、支架是否帮助解释、活动是否留下可修订的证据。

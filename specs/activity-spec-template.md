## 11. 活动验收

- [ ] 活动与章节成果直接对应；
- [ ] 最低环境可执行或有等效替代路径；
- [ ] 输入材料、版本、来源和许可明确；
- [ ] 教师已按声明程度核验步骤与参考结果；
- [ ] 学生能够形成可检查的学习证据；
- [ ] 评价量规测量目标成果而非操作熟练度；
- [ ] 安全、隐私、成本和社区风险已有处理；
- [ ] 失败与降级路径不会使核心学习成果消失。

早期序言 v0.2／v0.3 Word 和 127 页合并 PDF 已过时，本轮移出主分支，完整路径和固定版本恢复方法见[整理记录](../docs/repository-maintenance-2026-10-29.md)。它们的排版核验不适用于当前正文。

保留的 PDF 生成器见[脚本说明](../scripts/README.md)，其存在不代表已产出或验证当前打印版。
